# SOLUTION (Bear Guardian)

## 1. 解決したい課題
- 外出が多い家族（妻・子供）が「どこが危険か」「今近づかない方がよい場所は？」を即判断できる状況をつくる。
- 在宅の夫（エンジニア）が、最新の目撃情報を元に非侵襲な対策を素早く共有・更新できる状態をつくる。

## 2. 課題の解決方法（アプローチ）
- データ: 長野市のクマ目撃PDFを自動取得し、表を構造化。失敗時はモックCSVで即運用継続。
- 可視化: 緯度経度付きデータを folium で地図化し、ホットスポットを直感的に把握。
- 通知/共有: 最新目撃と頻出エリアをテキストダイジェスト化。LINE/Slack 送信用に拡張しやすいシンプル設計。
- 共存前提: 「避ける」「音や光で存在を知らせる」など非攻撃的アクションを提示。データは家族内共有を基本にして誤報拡散を防止。

## 3. 利用した技術スタック
- 言語: Python 3.10+
- ライブラリ: requests (PDF取得), pdfplumber (表抽出), pandas (整形), folium (地図生成)
- データ: 長野市公開PDF、失敗時は `data/sample_sightings.csv` のモックを利用
- 実行: ローカル実行のみで完結（Docker不要）。`pipeline.py pipeline` 一発で動作。

## 4. 実運用にあたってのランニングコスト（概算）
- 基本構成はローカルバッチのみ: 0円（自宅マシンで定期実行）。
- 通知をクラウド化する場合の例:
  - GitHub Actions で1日1回実行: 無料枠で十分。
  - LINE Messaging API / Slack Webhook: いずれも無料枠で運用可能。
  - オプションで地図タイル/ルートAPI (Google Maps/ORS): 月数ドル〜（小規模利用想定）。

## 付記（評価基準への対応）
- 適合性: 家族が外出時に「どこを避けるか」を即判断できる地図+ダイジェストを提供。
- 技術的実現性: 公開PDF更新に追従し、失敗してもモックにフォールバックする設計。
- エンジニアリング: 取得→構造化→可視化→共有を `pipeline.py` に統合し再現手順を明文化。
- 共存視点: 威嚇・駆除を行わず、回避と注意喚起に特化したアクションのみ提示。
