# 🐻 KumaSafe - ソリューション概要

## 1. 解決したい課題

### ユーザーの状況
- **家族構成**: 夫婦（30代）+ 子供1名
- **居住予定地**: 長野市内（新居から徒歩4分の場所で熊の目撃情報あり）
- **ライフスタイル**:
  - 夫: 自宅でリモートワーク（ITエンジニア）
  - 妻・子供: 幼稚園の送迎や買い物で日常的に外出

### 具体的な課題

#### 課題1: 漠然とした恐怖感
> 「いつ熊が出るかわからない」

**解決**: リアルタイムの目撃情報マップにより、**「いつ・どこで」**を可視化。
漠然とした恐怖を**具体的な情報**に変換し、適切な行動判断を支援。

#### 課題2: 外出時の不安
> 妻と子供が外出する際、夫は自宅で心配しながら待つしかない

**解決**: 
- 外出前の**安全チェック機能**で目的地の安全性を確認
- **LINE通知連携**で新規目撃情報を即座に家族全員へ共有
- 時間帯別の危険度表示で**外出タイミングの最適化**を支援

#### 課題3: 情報の分散
> 市の公式情報はPDFで公開されており、日常的なチェックが困難

**解決**: PDF自動解析スクリプトにより、公式データを**構造化・可視化**。
エンジニアである夫が運用可能な、持続可能なデータパイプラインを提供。

## 2. 課題の解決方法

### アプローチ: 「回避優先」の情報システム

```
┌─────────────────────────────────────────────────────────┐
│                    KumaSafe システム                      │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  [データ収集]     [分析・可視化]      [通知・行動支援]     │
│                                                          │
│  長野市PDF  ──→  地理情報に変換  ──→  マップ表示         │
│      │              │                    │              │
│      │              │                    ↓              │
│      │              │              安全チェック          │
│      │              │                    │              │
│      │              ↓                    ↓              │
│      └────→  時系列分析  ────→  LINE通知              │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### 主要機能の詳細

#### 1. 熊出没マップ
- OpenStreetMap + Leaflet によるインタラクティブマップ
- 目撃情報と痕跡情報を視覚的に区別（🐻 / 🐾）
- 危険度レベル（1-5）に応じた色分け

#### 2. 安全チェック機能
- 指定地点の半径2km以内の目撃情報を検索
- 時間帯に応じたリスク評価
  - 早朝（5-8時）: 高リスク（熊の活動が活発）
  - 日中（8-17時）: 低リスク
  - 夕方（17-20時）: 高リスク
  - 夜間: 中リスク

#### 3. LINE通知連携
- LINE Notify APIを活用した即座の情報共有
- 家族全員がLINEグループで受信可能
- 定期レポート機能（統計情報の配信）

#### 4. 共存ガイド
- 熊との遭遇を防ぐための予防策
- 万が一遭遇した場合の対処法
- 熊の生態理解を促進するコンテンツ

## 5. 動物愛護・共存の視点

### 設計原則

KumaSafeは以下の原則に基づいて設計されています：

1. **「回避」が最優先**
   - 駆除・捕獲を前提としない
   - 人間側が熊の行動エリアを理解し、適切に距離を保つ

2. **熊の生態を尊重**
   - 熊の活動時間帯（早朝・夕方）を考慮した警告
   - 季節による行動パターンの変化への対応

3. **教育・啓発**
   - 共存ガイドで熊の生態を理解
   - 「熊は本来人間を避けて生活している」ことを伝達

4. **攻撃的手段の排除**
   - 熊を傷つける機能は一切実装しない
   - 追い払い方法としても音を出す程度の穏やかな手段のみ紹介

### 共存のメッセージ

> 🐻 熊は森の生態系において重要な役割を果たしています。
> 彼らの生息地が人間の生活圏と重なることは避けられませんが、
> 私たちが正しい知識を持ち、適切な距離を保つことで、
> 互いを傷つけることなく共存することは可能です。
