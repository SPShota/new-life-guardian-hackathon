# SOLUTION.md - Kuma Radar

## 1. 解決したい課題

**「見えない恐怖」を「正しく避ける行動」へ変える。**

引越し直後のユーザー家族にとって、最大のストレスは「いつ、どこに出るかわからない」という**不確実性**です。
また、地理勘はあるものの、日常の買い物や子供の送迎ルート上に、実は直近でクマが出没していたとしても、自治体のPDFを見るまでは気づけません。

私たちは、単に「クマが出た」と騒ぎ立てるのではなく、**「自分たちの生活圏のどこにリスクがあるか」**を直感的に把握させ、**「遭遇しないための行動」**を自然に促すことで、家族の精神的な安心と物理的な安全を確保します。

## 2. 課題の解決方法

**共存を前提とした「Kuma Radar」の提供**

1.  **直感的なリスク可視化 (Visualization):**
    *   文字だけのPDF情報を地図上にプロット。夫だけでなく、妻や（将来的には）子供が見ても「あ、こっちは危ないね」とわかるUIを提供します。
    *   **工夫:** アイコンに愛嬌のある🐻を使用し、過度な恐怖心を煽らず、しかし注意喚起はしっかり行うデザインを採用。

2.  **行動変容を促すアラート (Actionable Alert):**
    *   「現在地を確認」機能により、自分の周囲500m以内のリスクを瞬時に判定。
    *   危険な場合: 「近くに目撃情報があります。落ち着いて離れましょう」と具体的な行動を指示。
    *   安全な場合: 「付近に目撃情報はありません（が、油断は禁物）」と安心感を与えつつ、注意レベルを維持。

3.  **エンジニア夫による運用容易性:**
    *   複雑なデータベースやバックエンドを排除。
    *   「PDFをスクリプトに通して、静的ファイルを置くだけ」という、エンジニアが最も手軽かつ確実にメンテナンスできる構成にしました。

**動物愛護・共存の視点:**
本ソリューションは、クマの捕獲や駆除を目的としません。
人間の側が彼らの領域（直近の出没場所）を把握し、**距離を取る（住み分ける）**ことで、不幸な接触事故を防ぐことを最大の目的としています。

## 3. 利用した技術スタック

*   **Frontend: HTML5, CSS3, JavaScript (Vanilla)**
    *   **選定理由:** ReactやVueのビルド環境構築の手間を省き、ファイルを開くだけ（または簡易サーバー）で即動作するポータビリティを重視。スマホブラウザでも軽量に動作します。
*   **Map Library: Leaflet.js (OpenStreetMap)**
    *   **選定理由:** Google Maps APIのようなAPIキー管理や課金リスクがなく、完全に無料で利用可能。長野市の詳細な地図データもOpenStreetMapで十分カバーされています。
*   **Data Processing: Python**
    *   **選定理由:** データ加工（ETL）分野でのデファクトスタンダードであり、PDF解析ライブラリも豊富。ユーザー（夫）のスキルセットとも合致します。

## 4. 実運用にあたって必要なランニングコスト

**概算費用: 0円**

*   **インフラ:** 静的サイト（HTML/JS/JSON）であるため、GitHub Pages, Vercel, Netlify等の無料枠で完全に運用可能です。
*   **地図データ:** OpenStreetMapを利用するため無料。
*   **API費用:** 不要。

維持費ゼロで、恒久的に家族の安全を守るシステムとして運用できます。
