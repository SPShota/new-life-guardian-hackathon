# Kuma Radar 🐻

家族の「安心」を守る、共存型クマ出没アラートマップ。
長野市の出没情報を可視化し、現在地周辺のリスクをリアルタイムに通知します。

## Prerequisites

*   **Web Browser:** モダンブラウザ（Chrome, Safari, Edge等）
    *   ※位置情報機能を使用するため。
*   **Python 3.x:** ローカル開発サーバーおよびデータ処理スクリプトの実行に利用。

## Setup & Installation

本プロジェクトはシンプルな静的サイト構成です。ローカルサーバーを立ち上げるだけで動作します。

1.  プロジェクトディレクトリへ移動します。
    ```bash
    cd solutions/gemini-3-pro-preview
    ```

2.  Pythonの簡易HTTPサーバーを起動します。
    ```bash
    python -m http.server 8000
    ```

3.  ブラウザで以下のURLにアクセスします。
    *   http://localhost:8000

## Data Pipeline

長野市のPDFデータを処理し、アプリケーションで利用可能なJSON形式に変換するためのスクリプトを用意しています。

### 手順

1.  `src/etl.py` を使用します。
    ```bash
    python src/etl.py
    ```
2.  現在はモックデータを生成するロジックになっています。
    *   **拡張:** `pdfplumber` などを導入し、実際のPDFパース処理を実装することで、自治体の最新データを自動で取り込めるようになります。
    *   生成されたJSONは `data/kuma_data.json` に配置（または上書き）して利用します。

## Usage

1.  **マップの確認:** 起動すると、長野市周辺の直近のクマ出没情報が「🐻」アイコンで表示されます。
2.  **詳細情報の確認:** アイコンをクリック、または下部のリストを確認すると、日時や状況（「成獣1頭」「フン」など）が表示されます。
3.  **現在地の確認 & アラート:**
    *   画面右下の「📍 現在地を確認」ボタンを押します。
    *   ブラウザの位置情報許可を求められるので「許可」します。
    *   現在地周辺（半径500m）に目撃情報がある場合、画面上部に**警告アラート**が表示されます。
    *   安全な場合も、その旨を通知し、安心感を提供します。
